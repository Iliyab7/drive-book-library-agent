# کتابخانهٔ خودکار PDF در Google Drive

این مخزن، بستهٔ راه‌اندازی یک کتابخانه با عامل هوش مصنوعی است. کاربر PDF را در `inbox` می‌گذارد؛ عامل، متن بازسازی‌شده و در صورت نیاز ترجمهٔ فارسی و HTML مطالعه/چاپ را در پوشهٔ اختصاصی کتاب داخل `output` تحویل می‌دهد. فهرست منابع و حافظهٔ مشترک فرایند در Google Sheets نگهداری می‌شوند. هماهنگ‌کننده، دو عامل جدا برای Review و QA به کار می‌گیرد.

## شروع برای استفاده‌کنندهٔ جدید

لینک همین مخزن را به Dot یا Codex حساب مقصد بدهید و پیام زیر را ارسال کنید:

```text
این مخزن را دریافت کن و START-HERE.md را کامل بخوان.
طبق آن، کتابخانه را در Google Drive همین حساب راه‌اندازی کن:
پوشه‌ها، اسکیل، Google Sheets به‌عنوان فهرست و حافظهٔ مشترک،
عامل‌های جداگانهٔ Review و QA، بررسی ساعتی و پایش توقف.
دسترسی‌ها و امکانات واقعی را بررسی کن، آزمون‌های راه‌اندازی را انجام بده
و راهنمای استفاده و لینک‌ها را تحویل بده.
اگر بستر آماده شد، فقط روشن بگو PDF را در کدام inbox بگذارم.
کارهای انجام‌شده را دوباره نساز و برای موارد مسدود، مانع دقیق را ثبت کن.
```

اگر عامل به GitHub دسترسی ندارد، نسخهٔ دانلودشدهٔ همین مخزن را به آن بدهید. عامل باید فایل‌ها را واقعاً بخواند؛ دانستن نام مخزن کافی نیست.

## چه دسترسی‌ای لازم است؟

- خواندن همین مخزن؛ ساخت فایل در پوشهٔ مورد تأیید Google Drive و ساخت/ویرایش Google Sheets.
- محیطی برای استخراج PDF و تولید فایل، و امکان واگذاری کار به دو زمینهٔ جدا.
- امکان ذخیره و اجرای زمان‌بندی با ابزارهای مورد اجازهٔ حساب مقصد.

عامل، تنظیمات را خودش انجام می‌دهد؛ ورود به حساب یا تأیید دسترسی‌ای که نیازمند صاحب حساب است، ممکن است یک بار لازم باشد. هیچ کلید یا حساب متصلی داخل این مخزن قرار ندارد.

## بعد از راه‌اندازی چه می‌کنیم؟

۱. PDF را در لینک `inbox` تحویلی بارگذاری کنید.
۲. پیام شروع و پس از قبولی، لینک پوشهٔ خروجی را در مقصد اعلان تنظیم‌شده دریافت کنید.
۳. برای انتخاب منابع بگویید: «اول فهرست مادر را بررسی کن؛ کتاب‌های مربوط به ... را انتخاب کن، سپس MDهای همان‌ها را بخوان.»

کتاب فارسی دو فایل `original.pdf` و `original.md` دارد؛ منبع غیرفارسی چهار فایل شامل `translation.fa.md` و `translation.fa.html` هم دارد. HTML همان ترجمه و دارای فونت داخلی برای مطالعه آفلاین و چاپ A4 است. وضعیت ترجمه منبع فارسی «نیاز ندارد» است؛ فایل/لینک صوری ساخته نمی‌شود. خطا و ناخوانایی مهم با وضعیت روشن ثبت می‌شوند؛ ترجمهٔ خلاصه‌شده جای کتاب کامل تحویل نمی‌شود.

## وضعیت این نسخه

بستهٔ راه‌اندازی نسخهٔ `2.0.0` است؛ انتشار این بسته، به‌معنی راه‌اندازی حساب دریافت‌کننده نیست. پایلوت اولیه تولید خروجی قابل‌قبولی داشته است. در پایلوت جاری، Dot از ثبت زمان‌بندی و آزمون خودکارِ یک PDF کوچک خبر داده؛ پایداری بلندمدت، تست کامل OCR و مقایسهٔ اجرایی هارنس‌ها هنوز تأیید نهایی مستقل ندارند. شرح دقیق در سابقه و شواهد آمده است.

این مخزن عمومی است؛ کتاب‌ها، گزارش‌های دارای محتوای شخصی، تنظیمات حساب و لینک‌های عملیاتی کتابخانه در Drive/Sheets خصوصیِ همان حساب می‌مانند و به Git اضافه نمی‌شوند. نسخهٔ عمومی، تاریخچهٔ Git مستقل و پاک‌سازی‌شده دارد؛ سابقهٔ فنی در مستندات حفظ شده است. استفاده از کد و مستندات این بسته تحت [مجوز MIT](LICENSE) مجاز است؛ این مجوز حقی نسبت به کتاب‌ها یا سایر منابع اشخاص ثالث ایجاد نمی‌کند.

## بررسی محلی بسته

Python 3.12 یا جدیدتر کافی است. خودِ بررسی‌ها آفلاین‌اند و به حساب Google یا مدل وصل نمی‌شوند؛ نصب اولیهٔ وابستگی به اینترنت یا کش بسته نیاز دارد:

```text
python -m pip install -r requirements-test.txt
python -B tools/validate_kit.py
python -B -m unittest discover -s tests -v
```

نمونهٔ PDF آماده در مخزن موجود است. فقط برای بازتولید آن، reportlab نیز لازم است و می‌توان `python tests/build_fixture.py` را اجرا کرد؛ بعد از هر تغییر واقعی فایل‌ها، manifest و شواهد نسخهٔ جدید باید به‌روز و بررسی شوند. این دستورها، Acceptance Test حساب مقصد را اجرا نمی‌کنند.

## نسخه ۲: اجرا و ارتقای نصب موجود

لاگ فعالیت، checkpoint، خطا/اصلاح و تحویل در برگه «رویدادها» در همان شیت مادر، همراه وضعیت جاری و روش مؤثر نگه‌داری می‌شود؛ حافظه چت مرجع ادامه نیست. عامل ابتدای هر نوبت آن را می‌خواند. retry شناسه یکسان دارد و قطع اتصال با outbox خصوصی و readback تطبیق می‌شود. [قرارداد و راه ابزار کوچک](docs/CONTENT-MODEL-FA.md)، [حافظه و قابلیت مقصد](docs/STATE-AND-DESTINATIONS-FA.md)، [ارتقای افزایشی نصب موجود](docs/UPGRADE-2-FA.md)، [گزارش نسخه](docs/RELEASE-2-FA.md).

نسخه ۲ قرارداد breaking دارد؛ نصب موجود خودکار تغییر نمی‌کند. ابزار این بسته استخراج‌کننده یا مترجم همه PDFها نیست: بازسازیِ شاهددار را به MD و HTML وصل می‌کند و راه انتخاب ابزار آزاد است. Drive/Sheets پیش‌فرض‌اند؛ مقصد دیگر با انتخاب مالک و احراز قابلیت‌ها. نبود scheduler یا delegation به محدودیت صریح می‌رسد؛ کار دستیِ پشتیبانی‌شده ممکن است، آمادگی بی‌نظارت ادعا نمی‌شود.

نمونه محلی (ترجمه مصنوعی ازپیش‌نوشته‌شده؛ بدون مدل/حساب زنده):

```text
python tools/book_pipeline.py tests/fixtures/v2/nonfa.json tests/fixtures/v2/nonfa.pdf runtime/demo/output runtime/demo/system
python tools/update_manifest.py
python -B tools/validate_kit.py
python -B -m unittest discover -s tests -v
```

برای چاپ/مشاهده واقعی نمونه، دستورهای [آزمون مرورگر](docs/CONTENT-MODEL-FA.md) را ببینید. مجوز فونت در [assets/fonts/OFL.txt](assets/fonts/OFL.txt) است؛ مجوز کتاب‌ها مستقل می‌ماند.
