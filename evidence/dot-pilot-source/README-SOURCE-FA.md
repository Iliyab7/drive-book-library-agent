# آرشیو خوانده‌شدهٔ بستهٔ Dot

این پوشه منبع تاریخی و شاهدِ گزارش اجرای پایلوت است؛ برای راه‌اندازی از START-HERE.md ریشهٔ مخزن استفاده کنید. دستورهای این آرشیو جای دستور جاری را نمی‌گیرند.

بستهٔ اصلی drive-book-library-v1.0.zip مستقیماً از Drive دریافت شد؛ CRC و هر ۳۴ فایلِ manifest اصلی با SHA-256 تطبیق داده شدند. نسخه‌های این پوشه برای انتقال پاک‌سازی شده‌اند: لینک‌های Google، هویت/شناسه‌های حساب و مسیرهای فضای کاری با نشانگر جایگزین شده‌اند. در نسخهٔ عمومی، نقل‌قول‌های دست‌نویس منبع حذف و برچسب نشست‌ها عمومی شده‌اند؛ نتایج فنی و محدودهٔ آزمون‌ها محفوظ‌اند. دادهٔ حساب مقصد از این پوشه کپی نشود. فایل package_release.py.txt فقط متن منبعِ ابزار بسته‌بندی Dot است و اجرا نمی‌شود.

SHA256SUMS.json، هش‌های فایل‌های خامِ بستهٔ اصلی را نگه می‌دارد؛ پس از پاک‌سازی، انتظار تطابق آن با فایل‌های این پوشه نداشته باشید. manifest ریشهٔ مخزن و provenance.json، نسخهٔ منتشرشدهٔ پاک‌سازی‌شده را پوشش می‌دهند.

گزارش‌های Review/QA و TEST_STATUS واقعاً داخل بسته دریافت و خوانده شدند. احکام آن‌ها به محدوده و هش‌های ثبت‌شده تعلق دارند؛ خواندن گزارش، تکرار مستقل همهٔ تست‌های عملیاتی یا بررسی منبع کتاب نیست. پیوند example.invalid عمدی و غیرفعال است و مقصد عملیاتی محسوب نمی‌شود.
