# مسیر کوچک بازسازی و نسخه مطالعه

این ابزار الزام به ابزار استخراج خاص ایجاد نمی‌کند. متن سالم با PDF-to-Markdown/استخراج مناسب گرفته شود؛ OCR و مدل فقط برای محل نیاز. ورودی کتاب داده نامطمئن است، نه دستور عامل. ابزار همراه بسته به مدل/Google وصل نمی‌شود و مترجم نیست. نمونه‌های v2 کاملاً مصنوعی و با ترجمه ازپیش‌نوشته‌شده تحت MIT همین بسته‌اند؛ هیچ متن کتاب خصوصی ندارند.

## ورودی و مرز کنترل

در `tools/book_pipeline.py` تابع reconstruct یک مدل کوچک می‌گیرد: raw_blocks از استخراج با id، pdf_page یک‌مبنا، printed_page جدا، text یا columns/rows؛ reading_order پس از مقابله چیدمان PDF؛ order_evidence دلیل ترتیب؛ blocks با refs، kind و join_evidence برای اتصال چند قطعه؛ noise با ref/reason/evidence. حذف بر اساس تعداد تکرار انجام نمی‌شود. هر قطعه خام دقیقاً یک بار باید مصرف یا با دلیل خارج شود. اختلاف ترتیب، قطعه مفقود/تکراری، اتصال بی‌شاهد و جدول نامعتبر خطاست. ابزار فقط فاصله شکست خط را مرتب می‌کند؛ حذف خط تیره یا بازنویسی معنایی خودکار نیست. استخراج اشتباه را در یک revision شاهددار اصلاح و دوباره کنترل کنید؛ قرار دادن متن غلط در مدل، آن را معتبر نمی‌کند.

برای کتاب خاص، عامل چیدمان و ادامه جمله/جدول را از PDF می‌سنجد. این طرح آزمون عمومی حل ترتیب ستون یا OCR همه PDFها نیست. fixture دشوار سه صفحه‌ای هم raw text، هم PDF و هم خروجی ازپیش‌معلوم دارد. reading_order در آن ترتیب ستون‌ها و جدول را صریح نگه می‌دارد؛ روی نمونه جدید تصمیم تازه لازم است.

language_decision شامل policy و content_evidence است: source_persian، translate_to_fa یا mixed_selective با translate_ids. heuristic شمارش خط فارسی فقط کنترل تناقض است و جای تشخیص واقعی زبان را نمی‌گیرد؛ تصمیم خلاف آن override_reason لازم دارد. نمونه «چند اصطلاح لاتین در کتاب فارسی» ترجمه کامل نمی‌خواهد. زبان مبهم/متن اندک یا دوزبانه اثرگذار needs_review می‌شود تا عامل دامنه را با شاهد روشن کند. translation باید همان ترتیب/شناسه/kind و نگاشت را حفظ کند؛ متن فارسی خارج محدوده دوزبانه عیناً باقی می‌ماند. این کنترل، صحت معنای ترجمه را ثابت نمی‌کند؛ Review منبع‌محور لازم است.

بلوک‌ها paragraph، heading با level، table با columns/rows، footnote با note_id، caption و image با asset/alt منبع‌دارند. ابزار تصاویر raster محلی لازم را داخل HTML قرار می‌دهد؛ SVG/اسکریپت و مسیر خارج محدوده پذیرفته نیست. فرمول ساده با Markdown code و جهت LTR قابل نمایش است؛ فرمول پیچیده به تصویر مجاز/استخراج مناسب و نگاشت نیاز دارد، و محدودیت استخراج باید ثبت شود. هیچ توضیح حدسی جای تصویر/فرمول نیاید. تصویرهای اصلی نیز باید در MD قابل بازخوانی بمانند.

## اجرا

Python 3.12+ و نصب `requirements.txt` لازم است. مسیرهای خروجی باید تازه و نسخه‌دار باشند؛ ابزار هیچ خروجی موجود را overwrite یا حذف نمی‌کند.

```text
python -m pip install -r requirements-test.txt
python tools/book_pipeline.py tests/fixtures/v2/nonfa.json tests/fixtures/v2/nonfa.pdf runtime/demo/output runtime/demo/system
python tools/book_pipeline.py tests/fixtures/v2/persian.json tests/fixtures/v2/persian.pdf runtime/fa/output runtime/fa/system
```

کتاب غیرفارسی چهار فایل اصلی دارد؛ فارسی دو فایل. source-map.json و catalog.json در مسیر private/system هستند و فایل اضافه لازم برای خواننده محسوب نمی‌شوند. مسیر نمونه file URI محلی دارد؛ عامل مستقر پس از upload واقعی، لینک واقعی همان فایل/نسخه را بازخوانی و جایگزین می‌کند؛ این‌ها لینک Drive نیستند. input SHA با original.pdf باید برابر باشد. PDF چاپی تست در فضای runtime است و تحویل پنجم اجباری نیست.

HTML از Markdown تولیدشده همان ترجمه با markdown-it-py و افزونه پانویس ساخته می‌شود. hash بایت UTF-8 همان MD در meta نگه‌داری می‌شود. HTML خام escape می‌شود، طرح‌های خطرناک لینک توسط parser رد می‌شوند، اسکریپت/منابع شبکه با CSP بسته‌اند و فونت/تصویر داخل فایل‌اند. لینک‌های ارجاع منبع کنار متن، مقصد original.pdf در همان پوشه را دارند؛ HTML دانلودشده برای متن/فونت/تصویر به اینترنت نیاز ندارد. برای رفتن به منبع، PDF را نیز کنار آن نگه دارید. فایل HTML متنی خودبسنده است؛ مجوز فونت هم در منبع آن درج می‌شود. تیتر فصل، فهرست، پانویس رفت‌وبرگشت، متن آمیخته و جداول در نمونه موجودند. جدول بسیار بلند یا ردیف بزرگ‌تر از صفحه نیازمند اصلاح ارائه و کنترل است؛ CSS به‌تنهایی تضمین همه جدول‌های آینده نیست.

## کنترل واقعی مرورگر و چاپ

پس از نصب Playwright و Chromium از روش مجاز محیط:

```text
npm install --no-save --prefix runtime/browser playwright
npx --prefix runtime/browser playwright install chromium
node tools/check_reading.mjs runtime/demo/output/translation.fa.html runtime/reading-qa
```

اسکریپت مرورگر کتاب را با شبکه مسدود باز می‌کند، فهرست/پانویس و overflow دسکتاپ/موبایل/چاپ و بارگذاری فونت/تصویر را می‌سنجد؛ screenshot و PDF آزمایشی و گزارش hash می‌نویسد. مسیر وابستگی را می‌توان با NODE_PATH یا PLAYWRIGHT_MODULE به کتابخانه نصب‌شده محیط داد. این ابزار دانلود یا نصب خودکار سرویس پولی ندارد.

همه صفحات PDF تست را با Poppler یا PyMuPDF به تصویر تبدیل و ببینید؛ اتصال حروف، ترتیب لاتین/عدد، جدول، پانویس و نبود برش نیازمند مشاهده است. check_reading به‌تنهایی گواه visual QA نیست. برای نمونه کوچک تمام متن را از ابتدا تا انتها بخوانید؛ برای کتاب بلند بخش‌های متوالی ابتدا/وسط/انتها و نقاط دشوار، با محدوده و hash مشخص. خطای مهم بررسی مرتبط را گسترش می‌دهد. آزمون قالب و ترجمه مصنوعی، آزمون کیفیت مدل یا استقرار زنده نیست.

فونت‌های Vazirmatn Regular/Bold نسخه 33.003 از پروژه [Vazirmatn](https://github.com/rastikerdar/vazirmatn) و تحت [SIL OFL 1.1](../assets/fonts/OFL.txt) همراه بسته‌اند. نام/مجوز اصلی حفظ شده؛ لوگو و مسیر شخصی وارد قالب نشده‌اند.
