# خواسته‌ها و محل پاسخ

این جدول نیازهای اولیه و اصلاح‌های بعدیِ طرح را به تحویل و آزمون وصل می‌کند. ادعای انجام همهٔ آزمون‌ها نیست.

| شناسه | خواسته | محل اجرای روش | آزمون |
|---|---|---|---|
| R01 | فقط قراردادن PDF در inbox و دریافت خروجی | START-HERE و WORKFLOW | AT01، AT03، AT12 |
| R02 | PDF اصلی، MD اصلی و MD فارسی در پوشهٔ مرتب | اسکیل و WORKFLOW | AT03، AT06 |
| R03 | استخراج دقیق، OCR و ترجمهٔ کامل و وفادار | اسکیل و دو پرامپت نقش | AT04، AT05، AT06 |
| R04 | اجرا، Review و QA با زمینهٔ جدا | START-HERE و prompts | AT02، AT08 |
| R05 | حافظهٔ مشترک؛ تصمیم نهایی Google Sheets | sheets.schema و WORKFLOW | AT07، AT08 |
| R06 | کشف سریع کتاب از متادیتا پیش از خواندن MDها | اسکیل و SETUP-AND-USE | AT07، AT09 |
| R07 | ثبت مسیرها، نتیجه‌ها و چرایی تصمیم‌ها | HISTORY-AND-DECISIONS و شیت روش | AT15 |
| R08 | بهینه‌سازی مصرف و ادامه پس از قطع/سقف حساب | WORKFLOW و پرامپت نوبت | AT10، AT11، AT14 |
| R09 | بررسی ساعتی، صف و پایش توقف | START-HERE و SCHEDULE | AT10، AT12، AT14 |
| R10 | پرامپت، اسکیل، دسترسی، مکانیزم و Acceptance Test | README و START-HERE و acceptance | AT01، AT15، AT16 |
| R11 | راه‌اندازی در حساب تازه با حداقل کار صاحب حساب | START-HERE و راهنمای ستاپ | AT01، AT02، AT16 |
| R12 | مقایسهٔ گزینه‌های هارنس برای همین کار | BENCHMARK و الگوی ثبت | AT17 |
| R13 | تحویل عمومی روی GitHub، بدون اطلاعات شخصی یا تنظیمات حساب | README و تنظیم visibility مخزن | AT16 |

درخواست اولیهٔ سه Dot مستقل، بعداً توسط صاحب پروژه به «همان Dot با دو عامل جدا برای Review و QA» تبدیل شد. پیشنهاد اولیهٔ Notion هم با Google Sheets جایگزین شد. بسته مطابق آخرین تصمیم است؛ سابقهٔ این تغییرها حذف نشده است.
